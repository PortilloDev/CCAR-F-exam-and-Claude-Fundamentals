## Content

Everything you need to follow along is available in two places: the slide decks (PDF) and the lab code on GitHub.

### 1. Slide Decks (PDF)

Download from the course materials page. The package includes:

- **One combined PDF**: `Ultimate Anthropic Claude Certified Architect - All Chapters.pdf` — contains every chapter in order. Use this to search across the whole course, print sections, or annotate as you go.
- Decks contain architecture diagrams, API and SDK call shapes, and checklists from the lectures.

### 2. Lab Code (GitHub)

Repository: `github.com/puria-izady/ultimate-ccar-f-labs`

```bash
git clone git@github.com:puria-izady/ultimate-ccar-f-labs.git
cd ultimate-ccar-f-labs
```

**Repository structure:**
- `lab_01/` through `lab_06/` — one folder per hands-on lab
- `labkit/` — shared helpers reused across labs:
  - Messages API Wrapper
  - Agents SDK Wrapper
  - Cost Calculation utilities
- Project files that pin Python dependencies

**Tip:** The videos walk you through building each solution from scratch. Following along is good; redoing the labs yourself deepens understanding for the exam.
